# JarvisGPT 🤖

JarvisGPT is an AI-powered personal assistant built using Python. It supports both voice and text interaction, allowing users to perform tasks, chat with an AI model, launch applications, and automate daily activities.

## Features

- Voice Commands
- Text Chat Interface
- AI Chat using Groq LLM
- Speech Recognition
- Text-to-Speech Responses
- Application Launcher
- System Control Commands
- Memory & Notes Support
- Task Management
- Modern GUI Interface
- Voice/Text Mode Toggle

## Technologies Used

- Python
- Groq API
- SpeechRecognition
- pyttsx3
- Tkinter / Flask
- JSON Storage
- OpenCV (Optional)
